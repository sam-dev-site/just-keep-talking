# Local preview

From this directory, run `pnpm install` (once), then `pnpm dev`, and open the local address printed by the development server.

Run `pnpm check` before handoff. The check covers the production build, content regressions, responsive browser behavior, console errors, horizontal overflow, and serious automated accessibility findings.

Publishing requires separate approval from the project owner. See `project/CLAUDE_HANDOFF.md` §5 before changing GitHub Pages settings or deleting root publish files.
